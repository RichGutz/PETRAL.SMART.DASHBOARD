GitBook: Se conecta directamente a tu repositorio de GitHub o GitLab. Lee tus archivos .md (Markdown) y genera automáticamente un sitio web de manuales de usuario súper profesional, ordenado por menús y con buscador integrado, que se actualiza solo cada vez que haces un git push.

Docsify / Docusaurus: Son generadores que levantan la documentación de usuario directo desde la carpeta docs/ de tu repositorio Git. Puedes redactar guías paso a paso con capturas de pantalla y mantenerlas versionadas junto con el código.

MkDocs + Material para GitHub Pages: Configuras un flujo en tu repo para que un script compile tu documentación en Markdown y la publique gratis en una web tipo [tudominio.com/docs](https://tudominio.com/docs).
